# vFlat 逆向工程與架構分析專案 (REA)

- **版本**：v0.1.0
- **目標應用**：vFlat Scan - PDF Scanner (`com.voyagerx.scanner`)
- **分析工具**：REA (Reverse Engineer Anything)、JADX / REA APK 分析模組

## 專案說明
本專案用於存放與記錄針對 vFlat Android 版本的逆向工程（REA）分析記錄、架構拆解、套件資訊與各項證據報告。

## 使用步驟
1. 將取得之 `vflat.apk`（或 `com.voyagerx.scanner.apk`）置於本專案根目錄。
2. 透過 REA 工具執行套件結構檢驗（`inspect_android_package`）、類別搜尋與反編譯分析。
3. 分析報告將統一彙整記錄於本專案中。
